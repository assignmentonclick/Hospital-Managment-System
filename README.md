# Hospital Management System

A professional front-end Hospital Management System built with HTML, CSS and JavaScript.

## Features
- Responsive landing page highlighting system capabilities with modern styling and animations
- Authentication page with basic login validation
- Dashboard to manage patients, doctors and appointments using local storage

## Usage
Open `index.html` in a browser to explore the landing page. Use the `Login` link and enter `admin` / `admin123` to access the dashboard.
